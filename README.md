## DEMOWIRE - DEmo WIreless REplay for Arduino

This is a very simple device to replay a OOK radio message using arduino and very cheap 433MHz module for remote controls.

Please read this article:

https://lipkowski.com/2026/11/24/simple-demo-of-hacking-a-wireless-doorbell/
